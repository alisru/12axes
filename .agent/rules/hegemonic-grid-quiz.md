# Hegemonic Decision Grid & Quiz Persona Invariants

## 1. The 9-Cell Decision Grid ($3 \times 3$) Architecture
All questions using the 2-Axis Decision Grid must map onto a $3 \times 3$ grid anchored strictly in the Geometry of Definitions and Psochic Hegemony:

- **Rows ($\psi$ - Action / Will)**:
  - Top Row ($+\psi = +1.15$): Civic / Direct Action ("Do").
  - Middle Row ($0\psi = 0$): Goodwill in Principle / IS / Present ("Principle").
  - Bottom Row ($-\psi = -1.15$): Defense / Counteraction ("Do Not").
- **Columns ($\upsilon$ - Scope / Morality)**:
  - Left Column ($+\upsilon = +1.15$): Universal / Public Good ("For Everyone").
  - Center Column ($0\upsilon = 0$): Direct Action / Institutional Defense / Center Origin.
  - Right Column ($-\upsilon = -1.15$): Individual / Personal Advantage / Self-Defense ("For Self / Group").

### Origin $(0, 0)$ Semantics
- Origin $(0, 0)$ is strictly the **Confusion / Uncertainty Zone** (*"I don't know / Not sure"*).
- Never assign an active compromise or status-quo policy position to $(0, 0)$.

## 2. Angle-Magnitude Polar Sector Answering Model
Belief is a polar vector $\vec{B} = (r, \beta)$:
- **Bearing $\beta$ (Direction)**: Partitions belief strictly between the 1 or 2 perimeter anchors in that sector. Zero radial bleed to the other 6 perimeter anchors ($0\%$).
- **Magnitude $m$ (Conviction)**: Scales conviction radially from Center $(0, 0)$ ($100\%$ Center) outward to the anchor ring ($R = 1.15$), where Center share reaches $0\%$.
- **Strict 100% Partition of Unity**: All shares must sum strictly to $100\%$.

## 3. Human UI Presentation & Ban on Debug Telemetry
- **Ban on Crammed Telemetry Bars**: Never display 3-column debug readouts with truncated labels (`Scope: FOR EV...`, `Action: - DISA...`, `Stance: 47%...`).
- **Single Dynamic Human Sentence**: The state readout must be a single, fluid, plain-English sentence that dynamically changes as the reticle moves.
- **No Meta-Labels in Option Text**: Never prepend labels like *"Agree in principle —"* or *"Reject taxation —"* into scenario bodies. The only acceptable explicit label is *"I don't know / Not sure"* in the center.

## 4. Grounded Pub Test Persona Standards
- The reviewer persona is a **real working person speaking plain, everyday English at the front bar**.
- **Ban Exaggerated Cartoon Stereotypes**: Never use Hollywood Crocodile Dundee stereotypes (*"crikey"*, *"fair dinkum mate"*, *"bonzer"*, *"struth"*).
- **Ban Academic Compound Word-Salad**: Use simple, grounded, observable terms.
- **Ban Mad-Libs Template Text**: Never concatenate raw database keys or pole tokens into user-facing sentences (e.g. `advance ${pole}`).

## 5. Safe Git Boundaries & Plan Archiving
- Upstream repositories (e.g. `RomanCypherpunk/12axes.git`) must be quarantined under `upstream`. Never push upstream.
- Commits are made locally to the user's workspace.
- Never overwrite implementation plans. Maintain numbered copies and diff logs in `_kanon_pr_plans/`.
